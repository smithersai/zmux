Run from the repository root with Zig 0.17.1. Do not modify source, push, or
publish. Record `jj --no-pager log -r @ -n 1`, `zig version`, host OS and
architecture (Linux x86_64 or macOS arm64), and execution trust level.

1. Run bounded coverage-guided fuzzing across every core subsystem:
   `zig build fuzz -Doptimize=ReleaseSafe --fuzz=1M --summary all`
   covering `buffer`, `protocol`, `rpc_line_reader`, `log`, `foreground`,
   `socket_path`, `pty`, `native`, `mux`, `connect`, `server`, `daemon`, and
   `sys`.
2. Run live PTY and UNIX-socket chaos fuzzing:
   `zig build fuzz-live --fuzz=500 --summary all`.
3. For any failing target:
   - Capture the exact failing seed hex and shrink/minimize it to the smallest
     reproducing byte sequence that still triggers the same assertion, panic,
     or error.
   - Deduplicate crashes by owning subsystem (`src/<module>/`), symbol name,
     and error or signal.
   - Check `test/fuzz/corpus.zig` and the subsystem's `test/fuzz/<module>.zig`
     to record whether an existing corpus seed already covers it.
   - Record recommended regression seed bytes and owning subsystem for
     archival.
4. When invoked with authenticated Smithers Cloud MCP access and crashes are
   found, file a deduplicated regression issue (`issue_create`) and attach the
   archived report artifact (`work_link_post`) referencing the minimized seed.

Write `.smithers/reports/fuzz-soak.json`:
```json
{
  "schema": "zmux.fuzz_soak.v2",
  "revision": "...",
  "zig_version": "0.17.1",

  "trust_level": "trusted|untrusted",
  "runs": [
    {"step": "fuzz", "iterations": "1M", "status": "passed|failed|skipped", "unique_paths": 0},
    {"step": "fuzz-live", "iterations": "500", "status": "passed|failed|skipped", "unique_paths": 0}
  ],
  "corpus_delta": {"new_seeds": 0, "minimized_seeds": 0},
  "crashes": [
    {
      "fingerprint": "module:symbol:signal",
      "module": "src/...",

      "minimized_hex": "...",

      "existing_seed": false
    }
  ],

}
```

Never fabricate pass results. Any step that did not run must be recorded as
`skipped` with the concrete reason.
